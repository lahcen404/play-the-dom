
# 🎮 Mini Games Project

## 🧠 Overview

This project includes two mini games built with **HTML, CSS, and JavaScript**:

* 🧩 **Memory Game** – Find all matching pairs.
* ⌨️ **Typing Speed Game** – Type the displayed text quickly and accurately.

---

## ⚙️ Features

### 🧩 Memory Game

* Dynamic grid generated with JavaScript
* Flip two cards at a time
* Matching pairs stay visible
* Tracks number of attempts and best score
* Victory message at the end

### ⌨️ Typing Speed Game

* Displays text to type
* Highlights correct and incorrect letters in real time
* Countdown timer (60s)
* Calculates WPM and accuracy
* Shows final score

---

## 🛠️ Technologies

* HTML
* CSS
* JavaScript
